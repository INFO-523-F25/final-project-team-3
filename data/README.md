# Data
-   **Spotify Playlists**: This dataset is based on the subset of users in the #nowplaying dataset who publish their #nowplaying tweets via Spotify. In principle, the dataset holds users, their playlists and the tracks contained in these playlists.
-   Source: https://www.kaggle.com/datasets/andrewmvd/spotify-playlists

## Variable Names and Descriptions:

-   **variable**: Description (with units, where applicable)

- __user_id__: hash of the user's Spotify user name
- __artistname__: the name of the artist
- __trackname__: the title of the track
- __playlistname__: the name of the playlist that contains this track

## Data Types:

-   __user_id__: String (UUID)
-   __artistname__: String
-   __trackname__: String
-   __playlistname__: String
